Task Lineage Workbench

Save a record of selected input and output files after a task, then compare it with a later run. The viewer separates changes to the inputs from changes to the results so you can see what needs investigation.

Experimental release · Standalone companion tool

What to expect from this release

What you get
A standalone file recorder, comparison viewer and command-line tool for Codex-related workflows. The new comparison controls run outside the Codex app.
Verified so far
File capture and comparison, guarded local fixture reruns, browser/package checks and a limited real Codex App Server diagnostic were executed.
Still needs testing or implementation
No model-backed Codex task was run as an end-to-end feature test. Automatic capture of task history, automatic AI reruns and cloud-task history are not implemented.
Relationship to the original app
Installing it does not change Codex or reveal the model's actual inputs. Connecting capture and reruns to real Codex tasks, or placing the viewer inside Codex, would require additional integration work.
